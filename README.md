# Sticky Panel

一个轻量的置顶"编辑板 + 待办"面板，用 Flutter 构建，支持 macOS 和 Windows，
界面跟随系统亮暗主题（Apple 风格配色）。

## 理念

上半部分是一块连续整体的富文本编辑板（flutter_quill），下半部分是文档的
实时待办视图。待办不用单独维护：文档里被打上 checkbox（任务列表）标记的
行自动汇总到下方待办区，两边是同一份文档——待办区打勾，文档里那行同步
变成已完成。

## 编辑板

- 一整块连续的富文本编辑器，像备忘录一样随手写
- 上方工具条：字号 / 加粗 / 背景高亮色 / 标题样式 / 任务列表 checkbox /
  撤销重做
- 选中行点工具条的 ☑ 即可把该行变成待办（或变回普通行）

## 待办区

- 实时解析当前项目文档：带 checkbox 标记的行汇总为待办，**按上方最近的
  标题行分组**——多段落并行时也能看清每条待办属于哪个大项
- 「本项目 / 全部」切换：全部视图按项目分组，跨项目追进度
- 点待办文字跳回编辑板里的来源行
- 展开按钮让待办区占满整个面板，只剩标题栏和操作区
- 菜单里可一键清除已完成待办（直接从文档中删除对应行）

## 其他

- 窗口置顶开关；多项目标签页（长按重命名/删除）
- 数据自动保存在本地（shared_preferences）

## 运行（macOS）

```sh
flutter pub get
flutter run -d macos
```

## Windows 构建

Windows 包由 GitHub Actions 构建：推送到 `main` 分支（或在 Actions 页手动
触发 `build-windows`），完成后在运行产物里下载 `sticky-panel-windows-x64`，
解压后运行 `sticky_panel.exe`。
