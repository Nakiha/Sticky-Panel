# Sticky Panel

一个轻量的置顶"编辑板 + 待办"面板，用 Flutter 构建，支持 macOS 和 Windows，
界面跟随系统亮暗主题（Apple 风格配色）。

## 理念

上半部分是一块随手写的编辑板，下半部分是从板子里"拉出来"的待办区。
待办不用单独维护：在板子里把某一行拉出为待办，它就会出现在下方待办区，
两边是同一条数据——待办区打勾，板里那行同步划线。

## 编辑板

- 每行就是一个输入框：回车开新行，空行按退格删除，可拖拽排序
- 行首输入 `# ` 自动变成标题行（也可用工具条的标题按钮）
- 选中某行出现样式工具条：拉出为待办 / 标题 / 加粗 / 五色高亮 / 字号
- 底部"添加一行"快速追加

## 待办区

- 自动汇总当前项目里所有被拉出的待办，**按所属标题分组**——多项目并行时
  也能看清每条待办属于哪个大项
- 「本项目 / 全部」切换：全部视图按项目分组，跨项目追进度
- 点待办文字跳回编辑板里的来源行
- 展开按钮让待办区占满整个面板，只剩标题栏和操作区
- 菜单里可一键清除已完成待办

## 其他

- 窗口置顶开关；多项目标签页（长按重命名/删除）
- 数据自动保存在本地（shared_preferences）

## 运行（macOS）

```sh
flutter pub get
flutter run -d macos
```

## Windows 构建

Windows 包由 GitHub Actions 构建：推送到 `main` 分支（或在 Actions 页手动
触发 `build-windows`），完成后在运行产物里下载 `sticky-panel-windows-x64`，
解压后运行 `sticky_panel.exe`。
