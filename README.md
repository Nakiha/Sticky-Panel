# Sticky Panel

一个轻量的置顶"编辑板 + 待办"面板，用 Flutter 构建，支持 macOS 和 Windows，
界面跟随系统亮暗主题（Apple 风格配色）。

## 理念

主体是一块连续的富文本编辑板（基于 flutter_quill），随手记、随便写。
需要追的事，划选那段文字，在浮出的小面板里点一下"列为待办"——它会带上
下划线标记，并出现在下方待办区。两边是同一份文档：待办区打勾，文档里
那段文字同步划线。

## 编辑板

- 连续的富文本文档，没有逐行的割裂感
- **划选文本**后底部浮出小面板：加粗 / 标题 / 字号 / 五色高亮 / 列为待办
- 被列为待办的文本带下划线，在文档里一眼可辨

## 待办区

- 自动汇总文档里所有被标记的文本片段，按所属标题分组——多项目并行时
  也能看清每条待办属于哪个大项
- 「本项目 / 全部」切换：全部视图按项目分组，跨项目追进度
- 点待办文字跳回编辑板并选中来源片段
- 展开按钮让待办区占满整个面板，只剩标题栏和待办
- 菜单里"清除已完成待办"会去掉完成项的待办标记（文字保留在文档里）

## 其他

- 窗口置顶开关；多项目标签页（长按重命名/删除）
- 数据自动保存在本地（shared_preferences）

## 运行（macOS）

```sh
flutter pub get
flutter run -d macos
```

## Windows 构建

Windows 包由 GitHub Actions 构建：推送到 `main` 分支（或在 Actions 页手动
触发 `build-windows`），完成后在运行产物里下载 `sticky-panel-windows-x64`，
解压后运行 `sticky_panel.exe`。
